A small, Pixel-inspired Android music player for MP3 files already stored on your device.

- Scans the device music library and groups MP3s into albums.
- Plays songs offline in a media-session foreground service, with lock-screen controls, shuffle, repeat, seek, and variable playback speed.
- Creates standalone custom albums (including empty albums), adds songs to them, gives albums their own cover images, and lets you hide albums, view only your own albums, hide songs, or mark favourites.
- Searches albums, animates GIF album covers, and uses the supplied bat image as the default launcher icon.
- Edits the title, artist, album, year, lyrics, and embedded cover image in the MP3's ID3 tags. Android may ask you to approve changes to a song.
- Offers light, dark, and system themes; selectable accent colours and launcher icons; and static-image or animated-GIF backgrounds.
- Opens a full now-playing screen with selectable animated visualizations, album artwork, and lyrics, with an optional sleep timer and a fine-grained 0.5x–2x playback-speed slider.
- Draws edge-to-edge with a full-height library view and a compact bottom navigation bar.
The app does not request internet access. Music, lyrics, artwork, and appearance settings stay on the device. MP3s play from their original files using the Android audio decoder; the app does not re-encode or artificially change their bitrate. Android selects the audio output format automatically. The Compose UI uses Android's default hardware-accelerated graphics
its only permissiions are CONTROL_AUDIO, CONTROL_AUDIO_PARTIAL< and Run foreground service.
